AI 旅行风险决策助手 · JourneyPilot · Windows x64 整合包
=====================================================

版本：V3
构建日期：2026-10-18
原项目：https://github.com/Lagom-TA/JourneyPilot.git
对比基线：main @ 20a79d5

本包包含
- 应用源码（后端、前端源码与已构建网页）
- 内置 Python 3.11 / Node / PostgreSQL 18 + pgvector / Redis
- 本地 CPU 向量模型（离线可用）
- MCP 服务依赖
- 使用说明、相对原版改动说明、文件级差异清单

本包不包含
- 任何人的 API Key（app/.env 不在包内）
- 制作人的聊天记录、行程、上传文件或数据库
- 运行时生成的 config.yaml、.state、日志和使用记录

首次启动
- 双击 start.cmd
- 按提示填写自己的模型 API 地址、模型名和 Key
- 等待数据库初始化，浏览器自动打开

验证记录
- 全量测试：746 passed，1 failed（既有计时竞态测试，与本次改动无关）
- Ruff：改动文件全部通过
- 真实运行：三天与四天武汉→杭州行程均完成生成
- 四天样例：8 个代表性景点候选，12 段路线中 8 段为高德/12306 实测

已知限制
- 酒店实时报价接口未接入：住宿候选与住宿费用可能为空
- 餐饮价格、部分市内交通费用可能未知，预算风险会显示“待核实”
- 超出天气预报窗口时使用季节资料，并明确标注不是当天预报
- 仅支持 Windows 10/11 x64，建议 8 GB 以上内存
