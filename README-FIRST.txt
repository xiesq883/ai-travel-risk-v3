AI 旅行风险决策助手 · JourneyPilot · Windows 64 位免安装版
==========================================================

第一次使用
1. 先将整个 ZIP 解压到本地可写目录，例如 D:\JourneyPilot。
   不要在压缩包内直接运行，不要放在 Program Files、只读目录或网盘同步目录。
2. 双击 start.cmd。首次启动按提示填写 API 地址、主模型、快速模型和 API Key。
   使用 DeepSeek 时前三项可直接回车；最后输入你自己的 Key（输入不显示）。
   其他兼容 OpenAI 的服务：填写自己的地址与模型名，可将主模型和快速模型填为同一模型。
3. 等待首次数据库初始化和启动，浏览器会自动打开风险评估页。
   默认地址：http://127.0.0.1:8011/?view=risk
   端口被占用时会自动选用附近空闲端口，以启动窗口显示的地址为准。

已经包含
- Windows x64 Python 3.11、Python 依赖、Node、天气工具依赖。
- PostgreSQL/pgvector、Redis；不需要安装数据库、Docker 或系统服务。
- 已构建网页、源码、四项风险引擎、可解释依据和方案优化闭环。
- 本地 CPU 向量模型，不需另行下载；知识库初始为空，可上传自己的资料。
- 最新默认值：户外活动 3 小时；交通可用时间默认等于需要交通时间；
  逐日缺失步行/活动/休息按每日强度预填，导入日期默认勾选交通完整核对。

日常使用
- start.cmd：启动并打开网页；已启动时直接打开。
- stop.cmd：停止此目录的后台服务，保留自己的数据。
- restart.cmd：重新启动并应用新 API 配置。
- configure-api.cmd：修改 API 地址、模型、Key；修改后运行 restart.cmd。
- status.cmd：检查组件状态。
- 关闭启动窗口不会退出后台服务，请用 stop.cmd。
- 移动整个文件夹前请先 stop.cmd；再次启动会使用新目录。

配置与数据
- Key 保存于 app/.env；自己的聊天、行程、数据库保存在 .state 和 app/data 等目录。
- 包内没有制作者的 Key、聊天、行程、上传文件或数据库。
- 初次填写 Key 只是保存配置，不会验证账号余额或模型权限。
- API 和网络工具使用时需要联网，模型调用费用由你自己的 API 账户承担。
- 高德/百度/付费搜索/航班服务默认禁用，需要时自行配置相应密钥。
  只填模型 API 即可使用聊天/规划及免密钥工具；精细国内路线等增强能力仍需对应服务凭据。
- 填充的默认值可修改；路线仍为估算时风险页面仍会提示待核实。
- Windows 10/11 x64，建议至少 8 GB 内存；仅本机访问，不公开监听外网。

故障处理
- 若提示 msvcp140.dll 或缺少 Microsoft Visual C++ 运行库，请安装微软官方 x64 运行库：
  https://aka.ms/vs/17/release/vc_redist.x64.exe ，然后重新启动。
- 首次启动较慢时，请等待；失败会提示 .state 内对应的日志。
- 模型报 401/403/404：检查 Key、余额/权限、API 地址及模型名，然后重启。
- 如 Windows 提示来自互联网的文件，请先核对来源；运行普通用户账号即可，无需管理员。
- 不要把已经使用过的整个文件夹再次发给别人（其中已有你的 Key 与个人数据）。
  分享时请发送最初收到的干净 ZIP。

开发与来源
完整应用源码在 app/src、app/frontend，编译后的网页在 app/static。
前端改动需要自己准备 Node/npm 重新构建；本包面向直接运行，无需构建。
